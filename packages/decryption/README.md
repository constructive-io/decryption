The `dcrypt` command line: encryption, BIP39 wallets and team secrets, all local-first.

This package is the short install name for [`@decryption/cli`](https://www.npmjs.com/package/@decryption/cli).
It holds no code of its own and runs the CLI at the exact version it depends on, so either install
gives you the same `dcrypt`.

## Installation

```bash
npm install -g decryption
dcrypt --help
```

## Usage

See the [`@decryption/cli` README](https://github.com/constructive-io/decryption/tree/main/packages/cli)
for every command, and the [repository](https://github.com/constructive-io/decryption) for the libraries
underneath.
